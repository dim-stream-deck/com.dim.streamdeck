# Changelog 3.3.5

## Fixes

- Prevent slow or unavailable checkpoint services from blocking plugin startup.
- Fix settings and selection messages between the plugin and the property inspector.
- Fix the Stream Deck Plus picker profile and its import format.
- Fix Farming Mode updates when multiple buttons use the action.
- Remove stale action listeners and run grid cleanup when the picker closes.
- Fix image caching and release rendering resources after use.

## Maintenance

- Update dependencies and migrate to Elgato Stream Deck SDK 3.
- Move the build tooling to Vite Plus and pnpm, and update the Node.js runtime to 26.
- Add regression tests for startup, property inspector messaging, picker profiles, action cleanup, and image rendering.
