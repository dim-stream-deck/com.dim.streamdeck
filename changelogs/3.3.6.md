# Changelog 3.3.6.0

## New

- Add Loadout Browser to browse and equip DIM and in-game loadouts, with class and hashtag filters, on Stream Deck, Mini, XL, Neo, and Stream Deck+.
- Update Pull Item keys and picker tiles with DIM-style tier pips, power, damage type, and item indicators for Champions, weapon frames, armor stats, seasons, masterworks, locks, and crafted or enhanced items.
- Add a global Appearance setting to choose between DIM style and Fill key layouts for item tiles.

## Fixes

- Fix item picker support for Stream Deck Neo, including its eight-key layout and picker profile.
- Open DIM's connection setup dialog when an action cannot reach DIM, with repeated setup requests limited to once every 30 seconds.
- Confirm saved and updated DIM authorization automatically for clients that support connection status checks.

The Loadout Browser and connection setup improvements require the corresponding DIM website update. Reselect saved Pull Item actions in an updated DIM instance to populate the additional item details.
